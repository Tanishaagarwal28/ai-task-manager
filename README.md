# AI Task Manager

## 🚀 Live Demo
https://ai-task-manager-lake.vercel.app

## 📂 GitHub Repo
https://github.com/Tanishaagarwal28/ai-task-manager

## 🛠 Tech Stack
- Next.js
- Supabase
- Tailwind CSS

## ✨ Features
- User Authentication (Signup/Login)
- Create Task
- Edit Task
- Delete Task
- Mark as Completed / Pending
- User-specific data (RLS security)

## ⚙️ Setup Instructions
1. Clone repo
2. Install dependencies:
   npm install
3. Add environment variables:
   NEXT_PUBLIC_SUPABASE_URL=
   NEXT_PUBLIC_SUPABASE_ANON_KEY=
4. Run:
   npm run dev
